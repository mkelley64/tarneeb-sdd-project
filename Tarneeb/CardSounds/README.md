# Card Foley

Source: Casino Audio 1.1 by Kenney Vleugels (Kenney.nl).
https://kenney.nl/assets/casino-audio

License: Creative Commons Zero (CC0 1.0).
https://creativecommons.org/publicdomain/zero/1.0/
Free for personal and commercial use; attribution is optional.

Bundled selection variants card-slide-1/2/3.wav derive from source
card-slide-1/2/4.ogg respectively. Landing variants use card-place-1/2/3.ogg;
collection variants use card-shove-1/2/3.ogg.

Conversion: decode to mono 44.1 kHz signed 16-bit PCM WAV; trim outside the
first/last sample exceeding 2.5% of source peak, retaining 4 ms before and
30 ms after; apply 3 ms linear edge fades; normalize each peak to 0.6.
Playback gain is defined by CardSoundToken, not baked into individual variants.
Original sound files are from kenney_casino-audio.zip downloaded 2026-09-16.
